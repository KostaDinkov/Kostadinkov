I've been writing code since I was 12 — BASIC, then Pascal, then a long list of things since. For the past three years I've owned a production ERP system end to end — architecture, backend, frontend, and now AI agents — used daily by a 15-person team. That's shaped how I think about AI-assisted development: speed from AI tooling is easy to get, trust in what it produces has to be earned deliberately. Mutation testing, property-based testing, and an independent AI code-review step — fresh context, no implementation history — are standard parts of how I ship, not afterthoughts.

## 🌟 Flagship Project

### [BakeryOps - Enterprise Management Suite](https://github.com/KostaDinkov/BakeryOps)

A production ERP system I own end to end, used daily by a 15-person team — real-time data visualization, order management, and AI-powered document processing.

- **Tech Stack:** TypeScript, React, Vite, ASP.NET Core, Docker
- **Engineering:** React Router v7, TanStack Query, SignalR real-time sync; mutation testing (Stryker.NET) and property-based testing (FsCheck/CsCheck) alongside Cypress, Playwright, and Vitest
- **AI Feature:** confidence-scored invoice/document extraction agent with human-in-the-loop approval before anything reaches the ledger
- **Status:** Production, with full CI/CD and observability (Grafana, Prometheus, Loki, Faro)
- **Related:** [Backend API](https://github.com/KostaDinkov/BakeryOps.Api) | [AI Components](https://github.com/KostaDinkov/BakeryOps.Ai) | [Thesis Research](https://github.com/KostaDinkov/BakeryOps.Thesis)
